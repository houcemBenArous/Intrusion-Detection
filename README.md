# TP 03: Analyse et Détection d'Intrusions à partir des Logs

Ce projet est une application web éducative qui présente les concepts et techniques d'analyse de logs pour la détection d'intrusions en cybersécurité.

## Fonctionnalités

- Présentation interactive des concepts de logs en cybersécurité
- Démonstration des commandes Linux pour l'analyse des logs
- Exemples de code Python pour le traitement et l'analyse des logs
- Visualisations graphiques des données de logs
- Simulation d'un système d'alerte en temps réel
- Interface responsive et moderne

## Installation

1. Clonez ce dépôt sur votre machine locale :

```bash
git clone https://github.com/votre-nom/tp03-analyse-logs.git
cd tp03-analyse-logs
```

2. Ouvrez le fichier `index.html` dans votre navigateur web.

## Structure du projet

- `index.html` - La page principale de l'application
- `styles.css` - Feuille de style pour l'interface utilisateur
- `script.js` - Fonctionnalités JavaScript interactives
- `web_server.log` - Exemple de fichier de logs pour les démonstrations

## Utilisation

### Navigation

Le site web est organisé en sections correspondant aux différentes parties du TP :

1. **Partie 1** : Introduction aux logs et leur importance en cybersécurité
2. **Partie 2** : Analyse des logs avec les commandes Linux
3. **Partie 3** : Analyse des logs avec Python et Pandas
4. **Partie 4** : Visualisation graphique des données de logs
5. **Partie 5** : Techniques de machine learning pour la détection d'intrusions
6. **Partie 6** : Surveillance en temps réel des logs
7. **Bonus** : Améliorations possibles et techniques avancées

### Exemples pratiques

Pour suivre les exemples pratiques :

1. Téléchargez le fichier `web_server.log` fourni
2. Exécutez les commandes Linux montrées dans les sections appropriées
3. Utilisez les extraits de code Python pour vos propres analyses

### Simulation d'alertes

Dans la section "Surveillance en temps réel", vous pouvez utiliser le bouton "Simuler une alerte" pour voir comment fonctionnerait un système de détection d'intrusion en temps réel.

## Prérequis techniques

Pour exécuter les exemples de code Python, vous aurez besoin de :

- Python 3.6+
- Bibliothèques : pandas, matplotlib, scikit-learn

Pour installer les dépendances :

```bash
pip install pandas matplotlib scikit-learn
```
